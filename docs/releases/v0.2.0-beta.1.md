## Scope

Approved Plex R3 English/Arabic typography and wordmarks, a compact accessible mobile menu, bilingual guidance, verified brand downloads, clear licensing and repository maintenance tools. The original editable marks remain preserved; font-independent delivery outlines avoid delayed Safari wordmark painting. Header navigation uses a disclosure button through 1024 px, with ordinary desktop navigation above that width.

Hosting only was deployed. Existing security headers, CI status, IAM, billing and ownership were preserved. No Functions, database rules, credentials or paid services were added. The owner will transfer the repository separately.

## Verification

- Local: 72 browser/theme/viewport cases, 432 transparent PNG exports, 36 keyboard/accessibility cases, 72 responsive-navigation cases and six no-JavaScript fallback checks across Chromium, Firefox and WebKit. Native Safari desktop and 320/390 px responsive review completed.
- Navigation scans had no axe violations. Overlay-related contrast indeterminates were reviewed using actual alpha compositing and visual inspection; minimum menu text contrast was 6.27:1. This does not establish full accessibility compliance.
- Exact Hosting-emulator preflight verified clean routes, exclusions, headers and 44 public file hashes. Live HTTPS verification matched all 44 public file hashes, all five revisioned logo/social URLs, the kit checksum and the default Hosting domain. HTTP redirects to HTTPS; Arabic trailing-slash routing and unknown-page 404 behavior passed.
- Live UI smoke tests passed 18 browser/language/viewport cases and six transparent PNG exports. Both GitHub assets are published, their server digests match local hashes, and their public HTTPS download endpoints respond successfully.
- The inherited extension-only cache rule missed clean HTML URLs. Explicit rules now revalidate `/`, `/ar` and `/404`. HTML, CSS, JavaScript and kit responses use `no-cache`; fonts retain `public, max-age=604800`. Security headers are unchanged.

Physical iOS/Android devices, human VoiceOver/NVDA acceptance and a complete accessibility audit remain unverified. This is a beta release. The prior Hosting version `e1fa23923d0c3b13` is recorded in local rollout evidence for rollback; no rollback was needed.
